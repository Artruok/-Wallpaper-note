# 壁纸笔记本 · Wallpaper Note

把要背的内容写在锁屏壁纸上，每天解锁都是一次复习。

- **包名**：`com.wallpapernote`
- **最低支持**：Android 8.0（API 26）
- **编译 / 目标**：Android 16（API 36）
- **技术栈**：Kotlin 2.1 + Jetpack Compose (Material 3) + WorkManager

---

## 功能

### 1. 自己上传壁纸

两种入口，按需选：

| 入口 | 机制 | 权限 |
|------|------|------|
| 从相册 | 系统 Photo Picker | 不需要任何存储权限 |
| 从文件 | SAF `OpenDocument` | 不需要任何存储权限 |

选中的图会立刻复制一份到应用私有目录，之后重启、清缓存、原图被删都不影响使用，完全离线。

### 2. 在壁纸上写字（透明背景）

每个文字块可调：

- **内容** — 多行文本，随便换行
- **位置** — 直接在预览上拖
- **大小** — 滑杆或双指捏合
- **旋转** — 滑杆或双指旋转
- **透明度** — 0% ~ 100%
- **字体** — 10 种系统字体，或导入自己的 `.ttf` / `.otf`
- **粗体 / 斜体**
- **颜色** — 15 色快选 + RGB 精调
- **阴影** — 模糊半径、水平偏移、垂直偏移、阴影颜色
- **描边** — 粗细 + 颜色
- **排版** — 左/中/右对齐、文本框宽度、行距、字距

一个文字组里可以放多个文字块，各自独立设置。

### 3. 应用为锁屏壁纸

只写 `WallpaperManager.FLAG_LOCK`，**桌面壁纸不受影响**。

### 4. 轮回记忆

- 一个「文字组」= 一屏要记的内容
- 多个组排成队列，按顺序轮回
- **自动**：每 N 天（1~30 可调）自动切到下一组并刷新锁屏
- **手动**：记住了就点主页的「下一轮回」，立刻跳到下一组
- 每组记录复习次数，顺序可在列表页上下调整

## 几个设计决策

**为什么坐标用比例而不是像素**
文字位置、字号、阴影半径全部按「占壁纸宽度的比例」存。换手机、换分辨率、横竖屏切换，排版都不跑位。

**为什么先裁图再写字**
底图先 center-crop 成屏幕尺寸的壁纸画布，再在这块画布上写字。这样预览里看到的位置就是锁屏上的位置，也不会被系统二次裁切切掉半行字。

**为什么用 WorkManager 而不是 AlarmManager**
Android 12+ 精确闹钟受限、Android 15/16 后台约束更严。WorkManager 每 6 小时探一次，由系统合并唤醒，省电且不会漏。App 冷启动时还会补一次「过期未轮换」检查，双保险。

**为什么不申请存储权限**
Photo Picker 和 SAF 都是用户主动选择的作用域授权，Android 13+ 的推荐做法，也不会在应用信息里显示吓人的权限列表。

## v1.1 更新（界面层级 / 控制页 / 动画 / 荣耀兼容）

### 1. 首启流程与两个主页面

- **首次打开（无文字组）**：直接进入「壁纸编辑」页（开始页），引导用户新增文字组、写字、设为锁屏。
- **首次成功应用锁屏壁纸后**：自动跳到「控制页」，之后每次启动都直接进控制页（状态 `hasCompletedSetup` 持久化）。
- **老用户（升级而来、已有文字组）**：视为已完成设置，直接进控制页。

### 2. 控制页（设置完成后主页面）

顶部显示「当前文字组」+ 第 X/N 轮 / 已复习次数，以及当前锁屏壁纸预览。下面按序排列：

1. **新增文字组** — 新建一组并进入编辑
2. **下一文字组** — 手动跳转下一组
3. **删除并进入下一文字组** — 删掉当前组、自动指向下一组（仅剩一组时保护不删）
4. **管理文字组** — 进入文字组列表（排序 / 复制 / 删除 / 编辑）
5. **编辑文字组** — 编辑当前组内容
6. **应用为锁屏壁纸** — 把当前组合成图写入锁屏

### 3. 顶栏汉堡菜单（三个横杠 ☰）

首页与控制页顶栏左侧有汉堡按钮，点开抽屉可切换「不同层级」：控制页 / 壁纸编辑 / 文字组管理 / 设置。

### 4. 动效（消除死板感）

- 页面之间切换：轻微上滑 + 淡入，旧页上滑淡出（`AnimatedContent`）。
- 控制页按钮：依次错位滑入 + 淡入（`Reveal` 错峰动画）。
- 所有按钮：按下轻微缩小、松手回弹（`ScaleButton` / `ScaleOutlinedButton`）。
- 配色沿用原有紫 + 薄荷绿方案（未改）。

### 5. 荣耀 / 新系统「壁纸样式」兼容

新系统（Android 13+）锁屏常有「时钟 / 杂志锁屏」等样式。处理原则：

- 本应用**只写入锁屏壁纸位图**（`WallpaperManager.FLAG_LOCK`），桌面壁纸与系统锁屏时钟等原生样式一律不动。
- 荣耀（MagicOS）/ 华为（EMUI）的锁屏时钟是系统绘制在壁纸位图**之上**的叠加层，按 FLAG_LOCK 写图不会影响它；荣耀设备应用成功后会提示「系统时钟等样式已保留」。
- 已做厂商检测（`Build.MANUFACTURER`/`BRAND` 含 honor/huawei）。**完整接管锁屏时钟位置/样式需要荣耀私有 SDK（HwWallpaperManager），不在标准 AOSP 公开 API 之内**，故采用上述标准做法。

## v1.2 更新（左右切换 / 左栏抽屉+压暗 / ☰→✕ / 关于 / 荣耀时钟新思路）

### 1. 页面切换改为左右滑动
- `AnimatedContent` 屏间切换由「上滑」改为「左右滑入滑出 + 淡入淡出」，带 `FastOutSlowInEasing` 缓动（约 300ms），不再生硬；并按前进 / 后退自动决定滑动方向。
- 控制页按钮错峰入场（`Reveal`）也改为从右向左滑入，整体统一为「左右」韵律。

### 2. 抽屉改为左侧一栏并压暗背景
- `ModalDrawerSheet` 固定宽度 300.dp，只占屏幕左侧；其余区域用默认 scrim 半透明压暗，点空白处即可关闭。
- 顶栏汉堡按钮：抽屉打开时显示 ✕（Close），关闭时显示 ☰（Menu），点一下切换开合，关掉更方便。

### 3. 新增「关于」（v1.3 一度移除，v1.3.2 起恢复）
- 抽屉最底部曾新增「关于」入口，弹窗介绍软件用途，并附作者联系方式：**B站 Asia_west**。v1.3 曾整段移除，v1.3.2 起恢复为「使用方法 + 联系方式」（去掉荣耀锁屏样式的说明文案）。

### 4. 荣耀 / MagicOS 锁屏时钟：换思路（重点）
- **问题根因**：MagicOS 有个已知 bug——用标准 API（`FLAG_LOCK`）写自定义锁屏壁纸后，系统锁屏时钟样式会丢失。v1.1 里「系统时钟等样式已保留」的说法在这类机型上并不成立，此处纠正。
- **新思路（不同做法）**：荣耀设备、且是用户主动点「应用为锁屏壁纸」时，不再直接写 `FLAG_LOCK`，而是把合成图经 `FileProvider` 交给**系统「壁纸和个性化」设置界面**去应用。由系统把时钟样式重新合成到锁屏之上，从而尽量保留原生时钟。
- 通过 `WallpaperManager.getCropAndSetWallpaperIntent()` 实现；若设备没有可用裁剪器则自动回退到直接写 `FLAG_LOCK`。
- **自动轮回**（WorkManager / 下一轮回 / 删除并进入下一）仍走直接写，不弹系统界面打断用户。

### 5. 启动图标（v1.3 起背景改为实体，见 v1.3）
- 初始版本曾把 `background` 设为透明，让笔记本本身成为图标；但透明 / 渐变背景的自适应图标在荣耀等启动器上均不显示，故 **v1.3 改为传统 PNG 图标（删除自适应图标 xml，改用各密度 `ic_launcher.png`）**（详见 v1.3 更新）。
- 前景重绘为「笔记本」：白色封面在紫底上清晰可见，加深一档紫的书脊做出厚度，页面横线用浅紫灰，末行换成薄荷绿强调线呼应 App 配色。
- 新增单色（monochrome）图标，供系统「主题图标」模式着色。

## v1.3 更新（图标改用 PNG / 去除返回箭头 / 关于含使用方法+联系）

### 1. 启动图标：改用传统 PNG（修复荣耀启动器不显示）
- 透明背景、渐变背景的**自适应图标（adaptive-icon）**在荣耀 / MagicOS 启动器上均被渲染成空白（连续两次失败），根因是荣耀启动器对 adaptive-icon 处理异常。
- 最终方案：**移除自适应图标**（删除 `mipmap-anydpi-v26/ic_launcher.xml` 及 foreground/background/monochrome 三个矢量），改用传统栅格 PNG 图标，按 mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi 各密度生成 `ic_launcher.png`（品牌紫渐变圆角底 + 白色笔记本）。所有启动器（含荣耀）都能正常显示。
- 代价：失去系统「主题图标」动态着色能力，但兼容性最稳。

### 2. 子页面去除返回箭头，统一用三条杠切换
- 壁纸编辑、文字组管理、设置三个子页面原本的左上角「← 返回」改为 ☰ 汉堡按钮，点击打开左侧抽屉，通过抽屉项切换页面（与主页 / 控制页一致）；抽屉打开时按钮变 ✕，点一下关抽屉。
- 系统返回手势仍保留：编辑页返回即放弃草稿，文字组 / 设置返回主页。

### 3. 「关于」：使用方法 + 联系方式
- 抽屉底部保留「关于」入口，弹窗介绍软件用途与**使用方法**（新建文字组、设为锁屏壁纸、文字组管理里调轮回顺序、自动轮换、完全离线），并附作者联系方式：**B站 Asia_west**。
- 不再写「荣耀锁屏时钟样式无法保住」那段说明（用户确认去掉）；功能上荣耀仍走系统「壁纸和个性化」去应用以尽量保留原生时钟。
